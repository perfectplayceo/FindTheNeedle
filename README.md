# 🪡 Найди иголку

![Найди иголку](assets/banner.svg)

Браузерная игра-кликер на HTML, CSS и JavaScript. Нужно перекопать стог сена, переработать сено в деньги и найти в нем иголку

**Репозиторий:** https://github.com/perfectplayceo/FindTheNeedle

---

## Как играть

1. Откройте игру, выберите слот сохранения и размер стога, нажмите «Новая игра».
2. Зажмите мышь или палец на стоге: вы копаете, сено летит на ленту.
3. Каждые T секунд лента отправляет партию в переработку: пресс, бумага, пеллеты. За переработанное сено вы получаете деньги.
4. Покупайте улучшения: быстрее копать, шире лопата, больше лента, автокликер, механические руки, экскаватор.
5. Когда иголка попадает на ленту, сканер должен её заметить. Нашли иголку и вы получаете награду, престиж и более плотный стог.

## Возможности

- Три слота сохранения (в `localStorage` браузера) и три размера стога: 12 000, 250 000 и 125 000 000 травинок.
- Экспорт и импорт сохранения кодом.
- Больше 20 улучшений в 8 группах: конвейер, копание, сканеры, алгоритмы, автоматизация, переработка, экономика, руки.
- Металлоискатель: пищит рядом с иголкой и с мусором.
- Грузовики с заказами: тюки со склада перетаскиваются в кузов.
- Престиж: каждая найденная иголка делает следующий стог плотнее, а доход выше.
- Тёмная и светлая тема подстраиваются под устройство. Игра работает на телефоне и на компьютере.

## Информатика в игре

### 1. Бинарный поиск

Стог разбит на 1440 клеток (48 × 30), и у каждой клетки есть номер от 0 до 1439. После покупки улучшения «Бинарный поиск» появляется панель с кнопкой «Запрос». Каждый запрос работает как шаг алгоритма:

```
mid = (lo + hi) // 2
если номер_иголки <= mid:  hi = mid
иначе:                     lo = mid + 1
```

Половина клеток, где иголки точно нет, затемняется. Игра показывает, сколько шагов уже сделано и сколько осталось.

| Алгоритм | Сложность | Шагов на 1440 клетках |
|---|---|---|
| Линейный поиск (копать подряд) | O(n) | до 1440 |
| Бинарный поиск | O(log₂ n) | не больше 11 |

![Бинарный поиск по шагам](assets/binary-search.svg)

![Линейный и бинарный поиск](assets/compare.svg)

Игрок сам видит разницу между алгоритмами: диапазон сужается в два раза на каждом шаге. Улучшение «Оптимизация запросов» удешевляет запросы.

### 2. Задачи по информатике

Кнопка «Получить задачу» выдаёт вопрос с четырьмя вариантами ответа. За верный ответ игрок получает деньги, за серию верных ответов награда растёт. Типы задач:

- перевод двоичного числа в десятичное и обратно (числа генерируются случайно);
- сколько раз нужно разделить диапазон пополам, чтобы остался один элемент;
- единицы измерения информации: бит, байт, килобайт;
- алгоритмы, линейный и бинарный поиск;
- память, переменные, кодирование.

### 3. Другие темы информатики, которые есть в коде

- **Хранение данных:** состояние игры превращается в JSON, а затем кодируется в Base64. Так получается код сохранения для экспорта и импорта.
- **Массивы:** стог хранится как одномерный массив `Float32Array`, а номер клетки считается как `y * W + x`.
- **Случайные числа:** стог, положение иголки и мусора генерируются случайно.
- **Автоматизация:** автокликер и механические руки работают как простые автономные процессы.

## Технологии

- HTML5 + CSS3 (переменные, `prefers-color-scheme`)
- JavaScript без библиотек и фреймворков
- Canvas 2D для графики
- Web Audio API для звуков
- `localStorage` для сохранений

Игра состоит из одного файла `index.html`: сборка не нужна, внешние библиотеки не используются, интернет после загрузки страницы не требуется.

## Запуск

**Онлайн:** откройте ссылку на GitHub Pages выше.

**Локально:**

```bash
git clone https://github.com/perfectplayceo/FindTheNeedle.git
cd FindTheNeedle
```

Затем откройте `index.html` двойным щелчком или перетащите его в окно браузера.

## Публикация на GitHub Pages

1. Загрузите `index.html` и `README.md` в репозиторий.
2. Откройте Settings → Pages.
3. В разделе Source выберите ветку `main` и папку `/ (root)`.
4. Через минуту-две игра откроется по адресу `https://perfectplayceo.github.io/FindTheNeedle/`.
